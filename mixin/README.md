В Java возможность использования миксинов появилась с дефолтными методами интерфейсов. Еще существует небольшая библиотека,
которая реализует миксины через аннотации - SpongePowered


Пример использования:
Возьмем игрового персонажа, которого можно кастомизировать добавляя различные способности.

1) Возможность ремонтировать самолеты
[PlaneMechanic](src/main/java/org/example/PlaneMechanic.java)
2) Возможность ремонтировать корабли
[ShipMechanic](src/main/java/org/example/ShipMechanic.java)
3) Прокаченный персонаж с умением чинить несколько единиц техники
[Mechanic](src/main/java/org/example/Mechanic.java)
